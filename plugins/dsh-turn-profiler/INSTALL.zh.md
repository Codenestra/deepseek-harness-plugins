# 回合级性能剖析器（dsh-turn-profiler）安装使用说明

版本：**0.1.0** · 维护者：Codenestra

逐轮时延瀑布图、token 与缓存诊断、实时指标和 JSON 导出。

## 安装与启用

1. 从本仓库的 [Releases](https://github.com/Codenestra/deepseek-harness-plugins/releases/tag/v0.1.0) 下载对应插件的 ZIP 并解压，或直接下载 `.tgz`。
2. 使用 DSH 的插件管理安装本地 `.tgz` bundle；若界面未提供本地文件入口，可让 DSH 对话中的代理通过 `plugin_manager` 的 `install_bundle` 安装，传入已下载的 `.tgz` 绝对路径。不要把 ZIP 当作插件安装包。
3. 包内带有 `cordis.patch.yml`，由插件管理器注册 host 和客户端入口。在插件页确认启用。
4. 如果宿主提示需要重启，等全部运行任务自然结束后，执行「重启应用与 Host」。然后检查对应侧栏入口。

**环境**：本版本在 Windows 桌面 DSH `0.1.7-rc.2` 本地构建上完成功能验收；Node.js 要求 `>=22.19.0`，Cordis peer 为 `~4.0.4`。其他 DSH 版本尚未做兼容性验收。

## 主要功能

- 逐轮瀑布图：LLM 首 token 等待 / 生成 / 各工具调用同轴展开；每步 token 与缓存悬停明细。
- 双计时源标注：历史=重建值（虚线）、插件运行期间=精确值（实线）；轮级徽标
  「精确计时 / 部分精确 / 重建计时」；精确行不被重建值降级。
- 实时模式：「● 实时」开关每 1.5 秒 ETag 条件轮询；开轮约 2 秒内出现「进行中」行，
  已落定步逐步进入瀑布图；开关与设置按浏览器持久化。
- 缓存诊断：逐轮命中率、缓存边界标记线（请求头变更原因）、逐步重发口径。
- 重试分析：被捕获的每次尝试为橙色段；轮级重试计数。
- 总览仪表盘：P50/P95 KPI、最慢工具/轮次 Top10、每日堆叠趋势。
- 导出：总览页「导出 JSON」按钮下载 summary + 会话 + 最多 2000 轮明细（跟随当前过滤器）。
- 显示设置：慢轮阈值秒数（默认 60，超阈值行橙色底纹）、语言（跟随系统/中文/English），
  仅存浏览器 localStorage。

## 配置与数据

- **无必填配置项**；开箱即用。显示设置位于面板顶部「显示设置」区。
- 数据目录：`<profile>/turn-profiler/turn-profiler.sqlite`（仅派生指标，不含消息正文）。
- 只读边界：仅经官方 session-query 读会话日志；不碰凭据、不跑 shell、不访问外网。
- host 侧改动（如升级覆盖 index.js/lib/）需重启应用；仅 client.js 改动刷新页面即可。

## 卸载

1. 在 desktop profile 移除本插件依赖与 bundle patch 行（或经插件管理禁用/移除该 bundle）；
2. 重启桌面应用；
3. 如需清理数据：删除 `<profile>/turn-profiler/` 目录（可选，删除后历史派生指标不可恢复）。

## 验收范围

功能验收已通过。连续 7 天真实使用观察仍是独立待办，本版本不宣称已完成长期稳定性观察。

额外 peer：`@deepseek-ai/dsh-llm >=0.1.7-rc.2`。历史回填依赖宿主 session-query 服务；工具耗时包含等待与审批时间，并行工具可能在时间轴上重叠。
