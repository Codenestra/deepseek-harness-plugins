# Project Hub · DeepSeek Harness Plugin

Cross-workspace overview, global search, project notes, session management, and quick switching.

- [中文安装与使用说明](INSTALL.zh.md)
- [Download v0.1.0](https://github.com/Codenestra/deepseek-harness-plugins/releases/tag/v0.1.0)

Install the `.tgz` as a local bundle through DSH plugin management, enable it, and restart the app and Host if required after all running tasks finish. The ZIP contains the installable TGZ and a Chinese Markdown guide.

This directory contains the accepted runtime sources, icon, locales, and bundle patch. Plain JavaScript; no build is required. Run `npm run check` for entry-point syntax checks. The package retains its `@local/dsh-project-hub` bundle identity.

Tested on Windows desktop DSH `0.1.7-rc.2` local build with Node.js >=22.19.0. Other host versions have not been verified. See the Chinese guide for configuration, limitations, and data locations.
