# 项目中枢（dsh-project-hub）安装使用说明

版本：**0.1.0** · 维护者：Codenestra

跨工作区总览、全局搜索、项目笔记、会话管理与快速切换。

## 安装与启用

1. 从本仓库的 [Releases](https://github.com/Codenestra/deepseek-harness-plugins/releases/tag/v0.1.0) 下载对应插件的 ZIP 并解压，或直接下载 `.tgz`。
2. 使用 DSH 的插件管理安装本地 `.tgz` bundle；若界面未提供本地文件入口，可让 DSH 对话中的代理通过 `plugin_manager` 的 `install_bundle` 安装，传入已下载的 `.tgz` 绝对路径。不要把 ZIP 当作插件安装包。
3. 包内带有 `cordis.patch.yml`，由插件管理器注册 host 和客户端入口。在插件页确认启用。
4. 如果宿主提示需要重启，等全部运行任务自然结束后，执行「重启应用与 Host」。然后检查对应侧栏入口。

**环境**：本版本在 Windows 桌面 DSH `0.1.7-rc.2` 本地构建上完成功能验收；Node.js 要求 `>=22.19.0`，Cordis peer 为 `~4.0.4`。其他 DSH 版本尚未做兼容性验收。

## 使用

- **总览**：查看全部工作区的顶层会话数、子代理数、最近活动和目录状态；可打开项目或在指定项目新建会话。
- **全局搜索**：输入文字，按项目筛选结果，点击命中项打开会话。全文检索依赖宿主的 session-query 服务与索引；索引关闭时，其余功能仍可使用。
- **详情与笔记**：编辑项目备注和固定指令，停止输入约 1 秒后自动保存。固定指令通过按钮复制，不会自动注入会话。笔记保存在 `<profile>/project-hub/notes.json`。
- **项目与会话管理**：重命名、排序、置顶、归档与取消归档。运行中的会话会明确显示「停止并归档」，该操作会停止对应任务。
- **快速切换**：点击右上角「切换器」，输入标题或路径片段；上下键选择，Enter 打开，Esc 关闭。

## 配置与已知边界

- 没有必填配置。若全文搜索提示索引关闭，检查 desktop profile 的 `cordis.patch.yml` 中 `@deepseek-ai/dsh-session-query-sqlite` 的 `openAt`，根据提示将 `never` 改为 `first-search`。修改后按宿主要求重启；插件不会自行更改全局索引配置。
- 验收环境的 `Ctrl+K` 被宿主占用，插件保留按钮入口。可在「设置 → 快捷键」为快速切换设置其他键位。
- 部分管理动作依赖宿主提供相应接口，缺失时会显示具体原因。

## 卸载

通过插件管理器禁用或移除 bundle。项目笔记单独保存在 `<profile>/project-hub/`；卸载前如需保留笔记，请备份该目录。卸载插件不会替你删除项目和会话。
